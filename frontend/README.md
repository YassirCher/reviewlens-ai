# ReviewLens Frontend

Premium Next.js 16 / React 19 / Tailwind CSS 4 interface for the ReviewLens POC.

## Run

```bash
cd frontend
npm install
npm run dev
```

The default backend base URL is `http://localhost:8000`. Override with:

```env
NEXT_PUBLIC_API_BASE_URL=http://localhost:8000
```

The browser never receives YouTube or AI provider API keys.

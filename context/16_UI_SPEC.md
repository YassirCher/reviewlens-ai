# UI / UX Specification

Brand: **ReviewLens**

Design direction:
- premium dark SaaS surface
- restrained glass panels, not excessive glassmorphism
- subtle grid and radial illumination
- strong typographic hierarchy
- compact status badges and score cards
- no generic chatbot layout
- expandable source-review cards
- clear evidence and confidence before decoration

Screens/states:
1. Hero search state
2. Live SSE progress state
3. Overall verdict dashboard
4. Expandable source-review cards
5. Optional audience-comment pulse
6. Error and partial-result warnings

Mobile:
- search button stacks below input
- score/report grid collapses cleanly
- thumbnail can hide on narrow width
- expandable evidence remains readable

Accessibility:
- semantic headings
- buttons for interactive cards/toggles
- visible focus state
- labels and ARIA where appropriate
- color is never the only verdict signal

# UI Design References

The frontend is an original ReviewLens design informed by current interface patterns visible on 21st.dev, especially its dashboard, card, AI-interface, and glass-surface collections.

References consulted:
- https://21st.dev/
- https://21st.dev/community/components/s/dashboard
- https://21st.dev/community/components/s/card
- https://21st.dev/community/components/s/ai
- https://21st.dev/community/components/s/liquid-glass

Principles adopted rather than copying a component:
- restrained dark SaaS shell,
- subtle glass cards,
- dense but readable evidence cards,
- compact status/progress UI,
- strong typography,
- expandable source detail,
- low-noise gradients and borders.
